Bandcamp Uploader — how to use (short)
======================================

Latest always (GitHub):
  https://github.com/ezixen/BandCamp-uploader
  https://github.com/ezixen/BandCamp-uploader/releases/latest
  ZIP:  https://github.com/ezixen/BandCamp-uploader/releases/latest/download/BandCamp-uploader.zip
  EXE:  https://github.com/ezixen/BandCamp-uploader/releases/latest/download/BandCamp-Uploader-exe.zip

EASIEST (no install) — EXE
--------------------------
1. Open folder: app\BandCamp-Uploader\
2. Double-click BandCamp-Uploader.exe
3. Log into Bandcamp in the Chrome window (once)
4. Paste an album folder path, press Enter; repeat for more albums
5. Review drafts in Chrome; you publish

Needs Google Chrome. Edit prices.txt next to the exe if you want.

Script path (PowerShell steps)
------------------------------
0. Run 0_associate_ps1.bat (first time — before install)
   - Associates .ps1 with built-in Windows PowerShell:
     %SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe
   - Clears other .ps1 open-with choices it can.
   - Or just use the .bat step files / the EXE above.

1. Run 1_install.bat (or 1_install.ps1) — first time only
   - Allow the Administrator / UAC prompt.
   - Installs Python (winget) and required packages.

2. Run 2_start_chrome.bat (or .ps1) and log in (once per PC / profile)

3. Optional — 3_check_titles.bat

4. Run 4_bandcamp_uploader.bat
   - Paths separated by ; also work in the script path.

How filenames work
------------------
  01. ezixen - intro.wav
  number, artist, " - ", title, .wav
  Underscores in titles become ?

Cover: largest .jpg / .jpeg in the folder.
Prices: edit prices.txt (album= / track=).
