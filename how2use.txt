Bandcamp Uploader — how to use (short)
======================================

1. Run 1_install.ps1 (first time only)
   - .\1_install.ps1
   - Allow the Administrator / UAC prompt.
   - Installs Python (winget) and required packages.

2. Run 2_start_chrome.ps1 and log in (once per PC / profile)
   - .\2_start_chrome.ps1
   - Log into Bandcamp in that window.
   - Password stays only in local-secrets\chrome-debug-profile on your PC.

3. Optional — check titles (spellcheck-style preview)
   - .\3_check_titles.ps1
   - Paste album folder path when asked, or:
     .\3_check_titles.ps1 "d:\music\ezixen\2026\ezixen - goasted (louder)"

4. Run the uploader
   - .\4_bandcamp_uploader.ps1
   - Paste the folder path, or pass it as a parameter.
   - Review the draft in Chrome; publish yourself. Script never publishes.

How filenames work
------------------
  01. ezixen - intro.wav

  number → order
  artist → stripped from title
  " - " → separator
  title → Bandcamp track title
  .wav only

  Underscores in titles become ?  (doll_ → doll?)

Cover: largest .jpg / .jpeg in the folder.

Prices: edit prices.txt anytime (album= / track=).
